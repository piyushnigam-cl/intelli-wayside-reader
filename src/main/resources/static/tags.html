Tag Read / Write

Reads every tag in front of the antenna. Change an EPC and press Write: the write is aimed at that tag's TID, so only that tag changes.

#TID (read only)EPC (edit, then Write) RSSIReadsResult
Press Read.

EPC: hex, a multiple of 4 digits (whole 16-bit words), up to 60. Reads and writes are refused while a train is passing. Writes run at the reader's write power; a tag that fails to write is usually too far away or facing the wrong way.
